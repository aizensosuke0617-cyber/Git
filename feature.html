this is my feature page this is my second change USEFUL COMMANDS FOR GIT 1. git init - Initialize a new Git repository 2. git clone - Clone an existing repository 3. git add - Stage changes for commit 4. git commit -m "commit message" - Commit staged changes with a message 5. git status - Check the status of the repository 6. git log - View the commit history 7. git diff - Show changes between commits 8. git branch - List, create, or delete branches 9. git checkout - Switch to a different branch 10. git merge - Merge changes from one branch into another 11. git pull - Fetch and merge changes from a remote repository 12. git push - Upload changes to a remote repository 13. git remote - Manage remote repositories 14. git stash - Temporarily save changes that are not ready to be committed
